# Volla Accessories Updater

A privileged system app for managing Volla accessories and updating their firmware. It shows up under **Settings → System** as "Volla Accessories".

Supported over USB right now: the Volla Tablet Keyboard, including its recovery mode.

## Building

Build it inside an AOSP tree as part of the platform.

```sh
m VollaAccessoriesUpdater
```
